## 🌟 项目概述

**BioLedger** 是一个基于联盟链的去中心化基因数据共享平台，致力于实现个人基因数据的**安全存储**、**授权共享**和**隐私保护**。平台基于 [微众银行 FISCO BCOS](https://fisco-bcos-doc.readthedocs.io/zh-cn/latest/) 联盟链，结合 MetaMask 钱包、OAuth2 协议、加密技术和 ERC20 代币激励机制，为数据提供者（如个人用户）和机构用户（如高校、制药公司、研究机构）提供安全、高效、可追溯的数据共享服务。

通过**权限分级**、**数据加密**和**水印溯源**技术，BioLedger 确保基因型数据的隐私性和可控性，同时通过代币奖励激励用户参与数据共享。数据提供者可通过授权数据获取奖励，机构用户可通过邮箱验证访问基因型数据，广泛应用于基因研究、药物开发等场景。

---

## 🚀 功能特性

- **🔐 用户认证**：通过 MetaMask 钱包实现安全登录和身份管理。
- **📥 数据获取与分类**：通过 OAuth2 协议从 WeGene 获取用户授权数据，按类型（如皮肤、运动）分类并生成哈希凭证。
- **🔒 权限管理**：
    - **普通用户**：上传基因数据并获取代币奖励。
    - **机构用户**：通过邮箱验证查看基因型数据。
- **🛡️ 数据隐私保护**：
    - 基因型数据采用 HCE（Hybrid CP-ABE with ECIES Encryption）加密。
    - 嵌入公钥水印，实现数据二次传播溯源。
    - 离线解密工具支持数据预览，禁止本地下载并设置数据过期机制。
- **💰 激励机制**：数据被查看时，数据提供者获 ERC20 代币奖励，可兑换数据分析服务或高校周边礼品。
- **🔍 数据溯源**：通过水印和智能合约追踪违规传播，封禁违规用户。

## 🏗️ 技术架构

BioLedger 采用以下技术栈构建，结合区块链和加密技术实现安全高效的数据共享：

| 模块              | 技术实现                           |
|-------------------|--------------------------------|
| **区块链**        | FISCO BCOS 联盟链，存储数据哈希、权限记录和代币交易 |
| **身份认证**      | MetaMask 钱包，提供以太坊兼容地址管理         |
| **数据对接**      | OAuth2 协议，与 WeGene 等第三方平台集成       |
| **数据存储**      | 链上：数据哈希、权限记录；链下：分布式数据库（如 IPFS）  |
| **加密技术**      | CP-ABE、ECIES                   |
| **智能合约**      | 权限管理、代币分发、违规封禁                 |
| **本地解密工具**  | 本地运行程序，支持数据预览与过期控制             |

## 🛠️ 安装与部署

### 环境要求
- **MetaMask**: 浏览器插件
- **FISCO BCOS**: 联盟链节点
- **数据库**: 支持分布式存储（如 IPFS 或 MySQL）

### 部署步骤
1. 配置 FISCO BCOS 联盟链节点，确保节点正常运行。
2. 安装 MetaMask 插件并连接到 BioLedger 的 FISCO BCOS 网络。
3. 设置分布式数据库（如 IPFS）用于链下数据存储。
4. 部署智能合约，配置权限管理和代币分发逻辑。
5. 启动本地解密工具，确保数据预览功能正常。

## 📖 使用说明

1. **用户登录**
    - 安装 MetaMask 插件，连接 BioLedger 的 FISCO BCOS 网络。
    - 通过 BioLedger 平台界面登录，授权 WeGene 数据访问。

2. **数据上传**
    - 普通用户上传基因数据，BioLedger 自动分类表现型数据和基因型数据，并为基因型数据生成哈希凭证。
    - 数据存储于链下，哈希记录于 FISCO BCOS 链上。

3. **数据查看**
    - 机构用户提交邮箱验证（如 `user@university.edu`）。
    - 验证通过后，申请查看基因型数据，接收加密数据包。
    - 使用 BioLedger 提供的本地解密工具，输入 MetaMask 私钥进行数据预览。

4. **奖励获取**
    - 数据被查看后，数据提供者自动获得 ERC20 代币。
    - 在 BioLedger 兑换页面使用代币兑换高校周边礼品或数据分析服务。

5. **违规处理**
    - BioLedger 通过水印监控数据二次传播。
    - 发现违规行为，智能合约自动封禁用户。
