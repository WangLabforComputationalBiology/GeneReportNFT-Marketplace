# Vue3 Webpage for Biochainer

Author: Tang Jiaming@SZTU BDI
Date: 2025.2 - 2025.8

## 项目介绍

基于 Vue3 的 BioChainer 前端页面，提供账户验证、合约交互功能以及数据共享功能模块。合约通过 MetaMask 钱包交互。

## 项目主要技术栈

- Vue3
- Vite
- Vue Router
- Pinia
- Element Plus
- Axios
- Ethers.js

## 项目启动

```bash
# 安装依赖
npm install

# 运行项目
npm run dev
```

## 项目部署

```bash
# 构建项目
npm run build

```
